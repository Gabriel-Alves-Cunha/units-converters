# Technology Stack

## Languages

- **TypeScript**: Primary language for development (`tsconfig.json`).

## Core Frameworks & Libraries

- **React 19**: Frontend UI library.
- **TanStack Start**: Full-stack React framework.
- **TanStack React Router**: Type-safe routing system.
- **Zustand**: Lightweight state management.
- **Valibot**: Schema validation library.

## Styling

- **Tailwind CSS v4**: Utility-first CSS framework (`@tailwindcss/vite`).
- **Lucide React**: Icon library.

## Runtime & Deployment

- **Bun**: JavaScript runtime, package manager, and test runner.
- **Cloudflare Workers**: Serverless execution environment.
- **Wrangler**: CLI for Cloudflare Workers.

## Development Tools

- **Vite**: Build tool and dev server.
- **Oxlint**: High-performance linter.
- **Oxfmt**: High-performance formatter.
- **Lingui**: Internationalization framework.
