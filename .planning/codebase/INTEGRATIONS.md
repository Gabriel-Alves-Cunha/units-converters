# External Integrations

## Analytics

- **PostHog**: Integrated via `src/integrations/posthog/provider.tsx` for product analytics and feature flags.

## Email Services

- **EmailJS**: Used in `src/components/feedback-section.tsx` for sending feedback directly from the client.

## Infrastructure & Cloud

- **Cloudflare**: The application is designed to run as a Cloudflare Worker, leveraging edge computing capabilities.

## Localization

- **Lingui**: Manages translation catalogs located in `src/locales/`.
